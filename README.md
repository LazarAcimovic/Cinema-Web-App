## Project Name
Cinema Web App

## Technologies
Frontend: Angular
Backend: Spring Boot
Database: PostgreSQL

## Description
Developed a scalable web app using Angular, Spring Boot, and PostgreSQL, enabling cinema
management with CRUD operations, advanced filtering, search, sorting, and reservation
tracking for films and halls.
